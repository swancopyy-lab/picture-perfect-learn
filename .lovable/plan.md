

# الإجابة على سؤالين

## 1. الصوت 🔊

نعم، فيه عدة خيارات أحسن من اللي نستخدمه حالياً (Web Speech API المدمج بالمتصفح):

| الخيار | الجودة | التكلفة | يدعم |
|--------|--------|---------|------|
| **ElevenLabs** | ممتازة (أصوات بشرية واقعية) | مدفوع — يحتاج API key | كل الكلمات والعبارات |
| **Free Dictionary API** | جيدة جداً (نطق Google الأصلي) | مجاني | الكلمات المفردة الإنجليزية فقط |
| **Web Speech (الحالي)** | متوسطة، تختلف بين الأجهزة | مجاني | كل شيء |

**اقتراحي الأفضل (مجاني + جودة عالية):** نستخدم **Free Dictionary API** للكلمات المفردة (نطق بشري حقيقي)، ونرجع لـ Web Speech للجمل والعبارات اللي ما تتوفر بالقاموس. هذا تحسين فوري بدون أي تكلفة أو إعدادات.

لو تبي ElevenLabs لاحقاً، يحتاج تفعيل Lovable Cloud + إضافة `ELEVENLABS_API_KEY`.

## 2. الصور 🖼️

نعم، تقدر ترسل أي رابط صورة من أي موقع — **مو لازم Unsplash**.

**يشتغل مباشرة:**
- روابط مباشرة تنتهي بـ `.jpg` / `.png` / `.webp`
- صور من Wikipedia, Pexels, Pixabay (روابط مباشرة)
- مثال: `https://upload.wikimedia.org/.../hammer.jpg`

**يحتاج تحويل يدوي مني:**
- روابط Unsplash بصيغة `unsplash.com/photos/...` (مو روابط صور مباشرة)
- وهذي اللي سببت مشاكل rate-limit سابقاً

**أفضل طريقة للإرسال:** انسخ رابط الصورة مباشرة (Right-click → Copy Image Address)، مش رابط الصفحة.

## الخطة المقترحة (Phase 1 — مجاني)

**الملف الوحيد المتأثر:** `src/data/vocabulary.ts`

تحديث دالة `speakWord()`:
1. لو الكلمة مفردة إنجليزية → جرّب جلب الصوت من `https://api.dictionaryapi.dev/api/v2/entries/en/{word}` واستخدم رابط الـ MP3 الموجود في الرد.
2. لو فشل أو كانت عبارة/جملة → ارجع لـ `speechSynthesis` الحالي.
3. cache النتائج في `Map` بالذاكرة عشان ما نكرر الطلبات.

النتيجة: نطق بشري أوضح للكلمات المفردة بدون أي تكلفة أو مفاتيح.
